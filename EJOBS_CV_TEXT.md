## Titlul proiectului

Security Log Analyzer — Python Cybersecurity Project

## Descriere scurta

Am dezvoltat o aplicatie Python pentru analiza offline a logurilor de autentificare. Aplicatia identifica tentative de brute force, posibile atacuri de tip credential stuffing si autentificari reusite dupa esecuri repetate. Genereaza rapoarte CSV si JSON si include teste automate rulate prin GitHub Actions.

## Tehnologii

Python, log analysis, cybersecurity, detection rules, CSV, JSON, unit testing, Git, GitHub Actions

## Cum il prezinti la interviu

Am creat un instrument defensiv care citeste loguri de autentificare si cauta tipare suspecte intr-o fereastra de timp configurabila. Am separat parsarea, analiza si raportarea in module diferite, am tratat datele invalide fara oprirea programului si am adaugat teste automate pentru regulile de detectie.
